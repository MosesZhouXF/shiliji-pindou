# 豆格 · 拼豆图纸工作台

纯浏览器图片转换工具。无需 API Key、后端或安装依赖；原图不上传。

## 本地运行

在本目录运行 `npm run dev`，打开 http://127.0.0.1:5173 。需要 Node.js 20 或更新版本。

`npm test` 运行转换引擎测试，`npm run check` 检查 JavaScript 语法。`dist/` 可直接部署到支持 ES modules 和 Web Worker 的静态托管服务；请通过 HTTP 打开，不使用 `file://`。

## 使用

1. 上传或拖入 JPG / PNG / WebP（最大 20 MB，最多 4000 万像素），或使用内置示例。
2. 选择算法、长边格数（16–160）、用色上限（2–48）；保持原图宽高比例，自动重新生成。
3. 可移除简单纯色外背景、查看原图、放大图纸、显示网格和色号。
4. 从当前用色或完整色板选择画笔色，配合画笔、橡皮、吸管精修。撤销 / 重做支持按钮及 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z。
5. 导出包含坐标、色号、十格分段和用量图例的 PNG、备料 CSV 或可再次导入的 JSON 工程。

重新转换会替换精修结果，可通过撤销恢复前一张图纸。关闭页面前保存工程。工程保存网格和色号，不保存原图；导入工程后仍可精修，重新转换需再次上传原图。手工精修可以增加颜色，用色上限仅限制自动转换。

## 算法

| 模式 | 方法 | 适合 |
| --- | --- | --- |
| 卡通保边 | 格内 RGB 颜色分组 + 主色采样；占比足够的深色轮廓优先 | 动漫、插画 |
| 照片保真 | 在线性光空间做区域平均 | 人像、宠物、摄影 |
| 结构抽象 | 3 倍网格采样，基于 Lab 颜色与位置的局部区域分配，迭代 3 次 | 需要简化的复杂图片 |
| 黑白线稿 | 局部深色保护 + 固定亮度阈值 | 简单线稿、单色标志 |
| 像素原样 | 中心点采样，不做平均和杂点清理 | 已有像素画 |

结构抽象是 **SLIC 启发的轻量版本**，不是 [Pixelated Image Abstraction](https://cragl.cs.gmu.edu/pixelate/) 的完整复现；没有实现论文的联合调色板退火。所有模式共用 Lab / CIEDE2000 色差匹配；当初始匹配颜色超限时，用加权感知误差降低量贪心选取真实色板子集。可选杂点清理仅合并四邻域中至少三个同色且色差小于 14 的孤立点，保护高对比特征；默认不做抖动。

外背景处理使用四角一致性检查与边缘连通洪泛，只适用于近似纯色背景。四角颜色不一致时保留背景并提示，不是通用 AI 抠图。

转换运行在独立 Web Worker 中，参数变化取消旧任务，避免旧结果覆盖新结果。暂未集成 AI 重绘、自动主体裁切或多品牌色板。

## 数据与边界

- `dist/palette.json`：291 个 MARD 色号；数据复用本地 `image-to-pindou` 技能随附的 `palettes/mard-291.csv`。屏幕 RGB 是参考值，未进行实体色卡校准。
- `dist/sample.svg`：本项目创建的矢量示例插画。
- `dist/engine.js`：不依赖 DOM 的转换与工程校验。
- `dist/worker.js`：浏览器后台转换入口。
- `dist/app.js`：导入、编辑、撤销与导出。
- 字体使用 Google Fonts；加载失败时回退系统字体，不影响转换。原图不发送给字体服务。
- 尺寸按 5 mm 拼豆估算，不包含底板边缘。实际图纸长边可能因极端长宽比形成很窄的另一边。

界面功能参考 [Webfem 拼豆生成器](https://webfem.com/tools/pindou/)，样式和代码独立实现。
